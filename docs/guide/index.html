WK Autoloader Store
v1.1.5
What it isInstallRestore

Jailbreak your PS5 from the Store tile.

WK Autoloader Store turns the PS5 Store tile into WK Autoloader. Open the Store icon, start the jailbreak (Relapse), and Elf Launcher opens when it finishes.

Download v1.1.5 Source on GitHub

Requirements

  1. PS5 firmware 7.00-13.60 (Relapse)
  2. elfldr listening on port 9021
  3. A way to send an ELF to elfldr (e.g. after a prior jailbreak)

Install

  1. Send the ELF. Send WK_Autoloader_Store_V1.1.5.elf to elfldr on port 9021.
  2. Reboot. Wait until install finishes, then reboot the console.
  3. Open the Store. Open the Store tile on the home screen.
  4. Start Jailbreak. Press Start Jailbreak. After Relapse completes, Elf Launcher opens automatically.

The tile works offline after install; you only send the ELF again to reinstall or update. Each install clears the old WebKit cache first, so the cache is always filled from scratch.

Restore the PlayStation Store tile

Send WK_Autoloader_Store_Restore_V1.1.5.elf to elfldr on port 9021, then reboot. This also clears the WK cache.
