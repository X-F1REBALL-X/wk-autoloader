Jailbreak your PS5 from the Store tile.

IgniKey remaps the PS5 Store tile so it opens a local jailbreak page with the Midnight UI. Pick a chain, press Start, done.

Download V1.0.0 Source on GitHub

What it is

A small ELF for the PS5. It points the Store tile (NPXS40047) to http://127.0.0.1:1022/app/index.html and serves the IgniKey page on port 1022. The page is cached on the console, so it keeps working after a reboot.

Supported firmware: 7.00-13.60. Chain: Relapse.

Install

  1. Start elfldr. Jailbreak once and make sure elfldr is listening on port 9021.
  2. Send the ELF. Send IgniKey_V1.0.0.elf from the release to elfldr on port 9021.
  3. Open the Store. The Store tile now opens IgniKey. Leave the chain on Auto or pick one, then press Start.

Undo

To get the normal Store back, send IgniKey_Store_Restore_V1.0.0.elf to elfldr on port 9021 the same way, then reboot the console.
